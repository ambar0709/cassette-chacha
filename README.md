# 📼 Cassette Chacha

**Chacha's tape collection** — a hand-picked catalog of gloriously fun desi web music players, all on one stage. Pick a station, then switch anytime; the background re-colours with each one.

🔗 **Live:** https://ambar0709.github.io/cassette-chacha/

## Stations
- **Deluxe Saloon** — 90s Bollywood barbershop bangers
- **Raju Mistri Ki Playlist** — 90s Hindi, non-stop
- **Horn OK Please** — truck-art road trip
- **Bus Driver** — 80s/90s night-service tapes
- **Deluxe Dhaba** — cinematic dhaba player (Rainy / Night modes)
- **Chai Wala** — steam, stillness & chai
- **Mehfil** — qawwali & ghazal courtyard

## Features
- One-tap switching between stations (only one plays at a time)
- Live per-station background theming
- ⭐ Favourites, 🎲 Surprise me, 🔗 shareable `#station` links
- 🎤 Optional mic-driven sound-reactive visualiser (on-device only)

## Add a cassette
Know a fun desi music-player site that belongs here? [Suggest a cassette](https://github.com/ambar0709/cassette-chacha/issues/new?labels=new-cassette&title=New+cassette%3A+) or open a [feature request / bug](https://github.com/ambar0709/cassette-chacha/issues/new?labels=enhancement).

## Tech
Single self-contained `index.html` (no build step). Embedded sites load in an iframe; audio and playback belong to those sites.
